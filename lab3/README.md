# Лабораторная работа № 3. Иерархическое проектирование. Модули и пакеты

**Вариант 7:** контроллер турникета из трёх модулей: обработка сигнала оплаты → автомат турникета из ЛР2 → привод турникета и счётчик проходов.

## Файлы

- `lab3_pkg.sv` — пакет: общие параметры (цена прохода, тайм-ауты, разрядности), типы `amount_t`, `count_t`, `timer_t`, перечисления `event_type_t`, `state_t`, `drive_state_t`, структуры `pay_in_t`, `event_t`, `motor_t`, функции `parity` и `pay_ok`
- `module_1.sv` — обработка сигнала оплаты: проверка посылки терминала (строб, ненулевая сумма, чётность), флаг `pay_error`, выделение фронта датчика прохода, формирование события `ev`
- `module_2.sv` — автомат турникета из ЛР2 (типы и параметры из пакета)
- `module_3.sv` — автомат привода (закрыт / открывается / открыт / закрывается, команды `motor.fwd`/`motor.rev`) и счётчик проходов `pass_count`
- `top.sv` — модуль верхнего уровня, соединяет три модуля
- `tb.sv` — самопроверяющийся тестбенч: 12 тестов (штатные проходы, граничные суммы, ошибки оплаты, проход без оплаты, тайм-аут, операции подряд, разворот привода, сброс во время работы и восстановление, 20 попыток прохода со случайной оплатой `$urandom_range(40,150)`), `$error` при расхождении, итог по тестам и проверкам
- `Отчет_ЛР3_ЯОА_вариант07_Ильин.docx` — отчёт

## Запуск

Нужен [Icarus Verilog](https://github.com/steveicarus/iverilog) (`brew install icarus-verilog`).

```bash
iverilog -g2012 -o lab3_sim lab3_pkg.sv module_1.sv module_2.sv module_3.sv top.sv tb.sv
vvp lab3_sim
```

Другая случайная последовательность оплат: `vvp lab3_sim +seed=5` (без `+seed` последовательность всегда одна и та же).

Временная диаграмма пишется в `lab3.vcd` (GTKWave, [Surfer](https://app.surfer-project.org) или расширение VS Code).
